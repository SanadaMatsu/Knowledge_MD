## ツール一覧

### 1. GitHub Copilot

| 属性 | 内容 |
|---|---|
| **種別** | 補完型 ＋ チャット型 |
| **提供元** | GitHub (Microsoft) |
| **価格モデル** | Individual: $10/月、Business: $19/ユーザー/月、Enterprise: $39/ユーザー/月 |
| **対応IDE** | VS Code, Visual Studio, JetBrains系, Vim/Neovim, Xcode |
| **クラウド必須** | はい（コード送信あり）|
| **オンプレ対応** | Enterprise プランで一部対応（GHE.com）|

**得意な開発フェーズ**

| フェーズ | 適合度 | 備考 |
|---|---|---|
| 要件定義 | ★★☆ | Copilot Chat でユースケース整理補助 |
| 設計 | ★★★ | アーキテクチャ相談、ドキュメント生成 |
| 実装 | ★★★★★ | コード補完の精度・速度が業界最高水準 |
| テスト | ★★★★ | テストコード自動生成、テスト説明生成 |
| 保守・リファクタ | ★★★★ | Copilot Edits でファイル横断編集 |
| コードレビュー | ★★★ | PR レビューコメント生成（Enterprise）|

**チーム規模適合性**
- 個人・小規模: ◎（Individual プラン）
- 中規模（10〜100名）: ◎（Business プラン）
- 大規模（100名超）: ◎（Enterprise プラン、ポリシー管理・監査ログ対応）

**強み**
- IDE 統合の完成度が高く学習コスト低
- GitHub との深い統合（PR, Issues, Actions 連携）
- Copilot Workspace で Issue から実装まで一貫フロー

**注意点・制約**
- コードがクラウドに送信されるため機密プロジェクトは規約確認必須
- Enterprise プランのコンテンツ除外設定を活用すること
- 生成コードのライセンス問題に注意（duplication detection 機能で緩和可）

### 2. Cursor

| 属性 | 内容 |
|---|---|
| **種別** | チャット型 ＋ エージェント型（AIファーストIDE）|
| **提供元** | Anysphere |
| **価格モデル** | Hobby: 無料（制限あり）、Pro: $20/月、Business: $40/ユーザー/月 |
| **対応IDE** | Cursor（VS Code フォーク）専用 |
| **クラウド必須** | はい |
| **オンプレ対応** | なし（Privacy Mode でコード保存は無効化可）|

**得意な開発フェーズ**

| フェーズ | 適合度 | 備考 |
|---|---|---|
| 要件定義 | ★★★ | チャットで仕様整理・設計案作成 |
| 設計 | ★★★★ | Composer でアーキテクチャ設計支援 |
| 実装 | ★★★★★ | Agent モードでファイル横断の自律実装 |
| テスト | ★★★★ | テストコード自動生成・実行連携 |
| 保守・リファクタ | ★★★★★ | コードベース全体を把握したリファクタ |
| コードレビュー | ★★★ | チャットでのレビュー指摘対応 |

**チーム規模適合性**
- 個人・小規模: ◎
- 中規模: ○（IDE 移行コストに注意）
- 大規模: △（IDE 統一の運用コスト、VS Code 拡張との互換性確認が必要）

**強み**
- コードベース全体を文脈として把握した高精度な提案
- Agent モードで複数ファイルにまたがる実装を自律実行
- `.cursorrules` でプロジェクト固有のコーディング規約を定義可能

**注意点・制約**
- VS Code フォークのため既存の VS Code 環境から移行が必要
- 特定の VS Code 拡張が動作しない場合あり
- Privacy Mode でもクラウド API を経由するため完全なエアギャップ環境には不向き

### 4. Devin

| 属性 | 内容 |
|---|---|
| **種別** | 完全自律型AIエンジニア（エージェント型）|
| **提供元** | Cognition AI |
| **価格モデル** | Core: $20/月（ACU制）、Teams/Enterprise: 要問い合わせ |
| **対応IDE** | ブラウザベース（独立環境）、Slack/GitHub 連携 |
| **クラウド必須** | はい（サンドボックス環境）|
| **オンプレ対応** | Enterprise で検討可 |

**得意な開発フェーズ**

| フェーズ | 適合度 | 備考 |
|---|---|---|
| 要件定義 | ★★☆ | Issue を読んで仕様整理 |
| 設計 | ★★★ | 実装計画の自律立案 |
| 実装 | ★★★★ | 長時間の自律タスク実行 |
| テスト | ★★★★ | テスト作成・実行・修正の自律ループ |
| 保守・リファクタ | ★★★ | バグ修正タスクの自律処理 |
| コードレビュー | ★★ | |

**チーム規模適合性**
- 個人・小規模: △（ACU コスト管理が必要）
- 中規模: ◎（繰り返し発生する定型タスクの自動化に最適）
- 大規模: ◎（並列タスク実行でスループット向上）

**強み**
- 人間が監督しながら長時間タスクを自律実行
- GitHub Issues / PR と直接連携した自律的な開発フロー
- Slack からタスク指示が可能

**注意点・制約**
- ACU（Agentic Compute Unit）消費モデルのためコスト予測が困難
- 完全自律のため重要コードへのアクセス権限管理が不可欠
- 複雑なドメイン知識が必要なタスクは精度が下がる場合あり
- 人間によるレビュー・承認フローとのセット運用が前提

| テスト | ★★★★ | ユニットテスト自動生成 |

- AWS 以外のクラウドやオンプレ中心のプロジェクトでは強みが薄い

## プロジェクト属性 × ツール適合性マッピング

### 開発フェーズ別推奨

| 主要フェーズ | 第1推奨 | 第2推奨 | 第3推奨 |
|---|---|---|---|
| 要件定義・設計 | GitHub Copilot | Cursor | Amazon Q Developer |
| 実装中心 | Cursor / Windsurf | GitHub Copilot | Codeium |
| テスト自動化 | GitHub Copilot | Amazon Q Developer | Cursor |
| 保守・リファクタ | Amazon Q Developer | GitHub Copilot | Cursor |
| 自律タスク処理 | Devin | Cursor (Agent) | Windsurf (Cascade) |

### セキュリティ要件別推奨

| セキュリティ要件 | 推奨ツール |
|---|---|
| クラウド送信OK | GitHub Copilot / Cursor / Windsurf |
| コード送信を最小化したい | GitHub Copilot (Exclusion設定) / Tabnine |
| オンプレ・エアギャップ必須 | Tabnine Enterprise / Continue.dev + ローカルLLM |
| AWS 環境でコンプライアンス重視 | Amazon Q Developer |

### チーム規模・予算別推奨

| 条件 | 推奨ツール |
|---|---|
| 少人数・予算最小（無料） | Codeium / Continue.dev / Windsurf Free |
| 個人〜小規模・標準 | GitHub Copilot Individual / Cursor Pro |
| 中〜大規模チーム | GitHub Copilot Business/Enterprise / Tabnine Enterprise |
| 自律化・効率最大化重視 | Devin + GitHub Copilot の併用 |

### 技術スタック別補足

| 技術スタック | 特記事項 |
|---|---|
| AWS 中心 | Amazon Q Developer を最優先検討 |
| 多様な IDE 混在 | Tabnine（最広 IDE 対応）/ Codeium |
| 特定言語ニッチ | Continue.dev（モデル選択自由度で補完）|
| モノレポ・大規模 | Cursor / GitHub Copilot Enterprise |
